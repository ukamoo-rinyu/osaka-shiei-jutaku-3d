# 大阪市営住宅 3Dマップ

大阪市営住宅の住棟を、国土交通省 PLATEAU の建物形状・高さで立ち上げた3Dマップです。
築年数・活用手法（市営住宅ストック総合活用計画）・耐震性・浸水リスク・入居募集対象空家・建替候補（古く募集がない住棟の目安）・交通（最寄り駅・バス停までの徒歩時間）で色分けし、住宅名で検索できます。

- 3Dマップ：`index.html`（GitHub Pages で公開）。左のパネルの「ツアー」で、住宅ごとに情報を出しながらまわりを1周する表示もできる（録画モードあり）
- 日影図：住棟・住宅をクリックしたときの「この号館の日影図」「住宅全体の日影図」。冬至日の真太陽時8〜16時・北緯35°で、時刻別日影線・等時間日影線・日影時間の濃淡を出す（`js/hikage.js`。太陽の位置の式と等時間線の引き方は「日影図・高さ制限チェッカー ver.4」から移植し、PLATEAU の建物の形のまま影を落とすようにしたもの。目安で、法令の判定ではない）
- 広告風画像メーカー：住宅のまとめの「広告風の画像を作る」。地図を撮影して、住宅から白い光が立ち上がる夜景風の画像に、周りの施設名・鉄道の線・最寄り駅・キャッチコピー・ロゴを重ねてPNGで保存できる（`js/koukoku.js`。画像には、実在の広告・入居募集とは関係ない旨の注意書きと地図の出典が入る）
- 確認・報告ページ：`check.html`（住宅ごとに号館の建物の違い・解体済み・一覧にない住棟を確認したり、3Dモデルがない住棟の直方体モデルや敷地範囲を描いたりして、Googleフォームで報告できるページ。作り直しは `python3 tools/build_check_page.py`。報告を受けて直す流れは `docs/report_workflow.md`）
- 住棟マスタ：`data/shiei_jutaku_master.csv`（住棟ごとの建設年度・築年数・耐震性・活用手法・PLATEAU建物ID・高さ・浸水深など）
- 入居募集対象空家：`data/shiei_jutaku_boshu_R080701.csv`（市営住宅一覧〈各区別〉R8.7.1 の住宅ごとの管理戸数・入居手続中等・募集中・募集準備中・入居募集対象外空家・備考。対応づけの根拠は `tools/boshu_r080701_map.py`、地図への反映は `tools/build_boshu.py`）
- 交通（最寄り駅・バス停）：`data/shiei_jutaku_kotsu_R080701.csv`（市営住宅一覧〈各区別〉R8.7.1 の「交通機関」欄を PDF の画像から読み取ったもの。読み取り結果は `tools/kotsu_r080701_transcribed.py`、地図への反映は `tools/build_kotsu.py`）
- 建築計画のお知らせ看板：`data/kanban_shiei_kdb.csv`（「建築計画のお知らせ看板情報」kdb.tokyo 大阪の検索結果から、市営住宅の建替とみられる49件を抜き出し、マップの住宅に対応づけたもの。地図への反映は `tools/build_kanban.py`）
- 浸水リスク一覧：`data/shiei_jutaku_flood_risk.csv`（上と同じ内容を浸水深の深い順に並べたもの）
- 確認用ツール：`tools/`（PLATEAU建物との対応づけを目視で確認・補正するために使ったHTMLと、確認・報告ページを作るスクリプト）

## 注意

- 個人が公開データをもとに作成したもので、大阪市の公式な資料ではありません。
- 住棟とPLATEAU建物の対応づけは、座標による自動判定のあと目視で確認・修正していますが、誤りが残っている可能性があります。
- PLATEAU（2024年度版）に建物がない新しい住棟は、位置だけ（半透明の箱）で表示しています。
- 浸水深は PLATEAU の災害リスク属性（洪水浸水想定区域〈想定最大規模・計画規模〉・高潮・津波）の最大値です。「浸水が及ぶ階」は1階あたり2.9mとした概算です。
- 団地の点線は、同じ住宅名の住棟を囲んで描いた目安で、実際の敷地境界ではありません。
